# Приоритет · мастерская учебных решений

Веб-приложение для настройки модели МАИ, определения контекстных приоритетов и планирования учебных ресурсов. Прикладная основа — магистерская работа Д. К. Зацепина «ИИ-компетентность будущего учителя математики» и тезисы Д. К. Зацепина и В. В. Абрамова о рейтинге ИИ-компетенций.

**Развёртывание:** GitHub Pages через [GitHub Actions](https://github.com/Alu-Vidor/ai-skills/actions/workflows/deploy-pages.yml). Адрес после успешной публикации: [alu-vidor.github.io/ai-skills](https://alu-vidor.github.io/ai-skills/).

## Публикация

В настройках репозитория **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. Это однократная настройка GitHub Pages, не требующая добавления токенов или секретов.

Workflow `.github/workflows/deploy-pages.yml` запускается при каждом push в `main` и вручную через **Run workflow**. Сначала проверяются расчёты и собирается `dist/`, затем официальный `actions/deploy-pages` публикует артефакт в окружение `github-pages`. При ошибке тестов публикация не выполняется. Для pull request предусмотрена отдельная проверка `check.yml`.

Приложение не зависит от Sites. Рабочий каталог публикации — `dist/`. Все URL относительные и учитывают размещение в `/ai-skills/`.

## Возможности

- Собственная цель, контекст, от 2 до 10 компонентов и от 2 до 10 критериев с произвольными названиями.
- Независимый выбор прямого ввода или парных сравнений для весов критериев и локальных приоритетов.
- Взаимно обратные матрицы, главный собственный вектор, CI/CR, настраиваемые RI и пороги.
- Синтез P = M · W, интерактивные сечения весов, аналитические границы смены лидера, одношаговые возмущения с проверкой CR.
- Часы, резерв, шаг, индивидуальные минимумы и максимумы. Сначала минимумы, затем распределение остатка по приоритетам с насыщением максимумов и методом наибольших остатков.
- Автосохранение в localStorage, экспорт и проверяемый импорт JSON, учебный план CSV.
- Адаптивный интерфейс, клавиатурная навигация, оформление для печати.

## Запуск

Нужен Node.js 20+. Внешних JavaScript-зависимостей нет.

```sh
npm run dev
# http://127.0.0.1:4173
npm test
npm run build
```

`dist/` содержит готовое статическое приложение. Все ссылки относительные, возможна публикация в подкаталоге GitHub Pages.

## Шаблоны и статус данных

Три сценария магистерской воспроизводят исходные независимые сравнения пяти компонентов по трём критериям. В `data/dissertation.json` сохранены условные авторские суждения и их обоснования. `data/reference-results.json` содержит ранее рассчитанные опорные результаты для автоматических тестов. При загрузке расчёты выполняются заново, результаты не подставляются из опорного файла.

Пример тезисов: шесть компонентов, пять критериев, W = (0,28; 0,18; 0,22; 0,24; 0,08) и исходная M. Парные сравнения в этом примере отсутствуют, применяется прямой ввод. При 36 часах, резерве 2 часа, шаге 2 часа и нулевых минимумах воспроизводится план (4, 6, 8, 8, 4, 4).

Пятикомпонентная модель магистерской и шестикомпонентная карта тезисов различаются. Их компоненты не отождествляются. Пользователь может изменять любой шаблон или начать с чистого листа. После изменения структуры новые пары получают значение 1.

Приоритеты не являются уровнями сформированности компетенций, вероятностями или оценками эффективности обучения. Перевод приоритетов в часы — самостоятельная проектная процедура с явно заданными ограничениями. Обязательные содержательные требования устанавливаются до ранжирования.

## Согласованность

Исходные RI по Саати (1994, с. 104): 3 → 0,52; 4 → 0,89; 5 → 1,11; 6 → 1,25; 7 → 1,35; 8 → 1,40; 9 → 1,45; 10 → 1,49. RI можно изменить. Для двух элементов CR равен нулю. Исходный порог трёх критериев — 0,05, компонентов — 0,10. Пользовательские пороги сохраняются при изменении структуры.

Saaty, T. L. How to Make a Decision: The Analytic Hierarchy Process. *Aestimum. Atti del XXIV Incontro di Studio* (1994), pp. 75–105, таблица RI на с. 104. [Первоисточник](https://oaj.fupress.net/index.php/ceset/article/view/6254), DOI: 10.13128/Aestimum-7138. Электронная публикация размещена в 2009 году.

## Конфиденциальность

Серверной базы и учётных записей нет. Расчёты и проекты хранятся в браузере пользователя, между устройствами автоматически не синхронизируются. Сохраните JSON для резервной копии. Шрифт Golos Text загружается с Google Fonts, при отсутствии сети используется системный шрифт. Рукопись, персональные данные, ключи и служебные материалы в репозиторий не включены.

## Структура

`src/math.js` — чистые вычисления. `src/app.js` — конструктор и интерфейс. `src/style.css` — адаптивное оформление. `tests/math.test.mjs` — проверка по независимым опорным результатам и ограничениям распределения. `scripts/` — сборка и локальный сервер.
